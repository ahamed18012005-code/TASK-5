# PhishAware — Phishing Awareness and Incident Response Simulation

## Project Overview

PhishAware is a cybersecurity awareness project developed using Python. It demonstrates how common phishing indicators can be identified in a fictional email and how a simulated incident response process can be documented.

This project is intended for educational purposes and safe cybersecurity practice.

## Objectives

* Identify common phishing indicators in a sample email.
* Detect urgent or threatening language.
* Identify account verification requests.
* Detect URLs in email text.
* Demonstrate the stages of incident response.
* Generate a timestamped incident response evidence log.
* Recommend practical measures to reduce phishing risks.

## Project Components

### 1. Phishing Email Detector

File: `phishing_detector.py`

The detector reads a fictional email from `samples/mock_phishing_email.txt` and checks for configured indicators:

* Urgent or threatening language
* Account verification requests
* URLs beginning with HTTP or HTTPS

When indicators are found, the program displays alerts and recommends manual review.

### 2. Incident Response Simulation

File: `incident_response.py`

The script demonstrates six incident response stages:

1. Detection
2. Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

It prints the stages and saves a timestamped log to `evidence/incident-response-log.txt`.

## How to Run

Make sure Python 3 is installed and open a terminal in the project directory.

Run the phishing detector:

```bash
python phishing_detector.py
```

Run the incident response simulation:

```bash
python incident_response.py
```

On some systems, use `python3` instead of `python`.

## Expected Results

The detector should report the indicators present in the supplied fictional sample email and recommend manual review.

The incident response script should display the six stages and create an evidence log.

Actual output should be checked by running the scripts. These tools are basic educational demonstrations, not production-grade security systems.

## Security Recommendations

* Verify the sender's email address.
* Avoid clicking unexpected or suspicious links.
* Access important accounts through their official websites or applications.
* Do not share passwords or one-time verification codes through email.
* Report suspicious messages to the appropriate support or security team.
* Provide regular phishing-awareness training.

## Limitations

* The detector uses predefined keywords and simple URL checks.
* Legitimate emails may trigger alerts.
* Phishing messages may evade detection if they do not contain configured indicators.
* The program does not verify sender identity, follow URLs, scan attachments, or use machine learning.
* The incident response program simulates actions; it does not perform real containment, eradication, or system recovery.

## Ethical Considerations

Only fictional sample data is used for this demonstration. No real accounts, credentials, or systems are accessed or modified by the scripts.
